¡Configuración e instalación completada con éxito!
Para activar el entorno virtual en tu terminal ejecutá:
    source venv/bin/activate

Para inicializar la base de datos de la API:
    sudo mysql
        (en mysql): #cambiar la pass del usuario root
        ALTER USER 'root'@'localhost' IDENTIFIED WITH caching_sha2_password BY 'root';
        FLUSH PRIVILEGES;
        EXIT;
    mysql -u root -p < db/init_db.sql

Para iniciar el servidor Flask:
    python app.py

A partir de aca, queda levantado el servicio
Desde postman se le puede pegar a los endpoint que vayamos desarrollando
